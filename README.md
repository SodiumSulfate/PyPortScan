## 项目概述

PyPortScan是一款基于Python和Kivy开发的端口扫描工具，提供了直观的图形界面，支持快速、准确地扫描目标主机的开放端口。该工具适用于网络管理员、安全测试人员和普通用户，可用于检测网络设备的开放端口、评估系统安全状况或调试网络连接问题。

## 功能特性

- 🎯 **多目标支持**：支持IP地址和域名扫描
- 🔢 **灵活的端口设置**：支持端口范围（如1-1024）和特定端口（如80,443,3389）
- ⚡ **高速扫描**：支持自定义线程数，提高扫描效率
- 📊 **实时进度显示**：直观的进度条和状态信息
- 💾 **结果保存**：支持将扫描结果保存为TXT文件
- 🎨 **现代化界面**：采用深色主题设计，支持窗口拖动和大小调整
- 🚀 **独立运行**：无需安装Python或其他依赖，直接运行可执行文件

## 安装指南

### 从GitHub下载

1. 访问项目GitHub仓库
2. 进入"Releases"页面
3. 下载最新版本的可执行文件（.exe）

### 从源代码构建

#### 系统要求

- Python 3.7或更高版本
- pip包管理器

#### 安装步骤

1. 克隆项目仓库：
   ```bash
   git clone https://github.com/SodiumSulfate/PyPortScan.git
   cd PyPortScan
   ```

2. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```

3. 运行应用：
   ```bash
   python run.py
   ```

4. 使用PyInstaller打包（可选）：
   ```bash
   pyinstaller --onefile --windowed --add-data "DATA.dat;." --add-data "loading.dat;." run.py
   ```

## 使用说明

### 基本操作

1. 启动PyPortScan应用
2. 在"目标IP/域名"输入框中输入要扫描的目标地址
3. 在"端口范围"输入框中设置要扫描的端口范围
4. 调整"线程数"和"超时时间"参数
5. 点击"开始扫描"按钮
6. 观察进度条和状态信息
7. 扫描完成后，查看结果显示区域
8. 可选择将结果保存为TXT文件

### 端口范围格式

- 单个端口：`80`
- 连续端口范围：`1-1024`
- 多个端口：`80,443,3389,22`
- 混合格式：`1-100,8080,9090`

### 最佳实践

- 对于大规模扫描，建议适当降低线程数，避免系统资源占用过高
- 对于不稳定的网络环境，建议适当增加超时时间
- 扫描完成后，及时保存重要的扫描结果
- 仅扫描您拥有合法授权的目标系统

## 资源文件制作

### DATA.dat 制作方法

DATA.dat 是一个加密的 ZIP 文件，包含软件运行所需的字体和背景图片。制作步骤如下：

1. **准备资源文件**：
   - 字体文件：`MapleMono-NF-CN-Light.ttf`（或其他您喜欢的字体文件）
   - 背景图片：`bgp.png`（建议使用1:1比例的图片）

2. **创建 ZIP 文件**：
   - 将字体文件和背景图片放入同一文件夹
   - 使用 ZIP 压缩软件（如 WinRAR、7-Zip 等）创建 ZIP 文件
   - 设置压缩密码（请记住此密码，后续需要在代码中使用）
   - 将创建的 ZIP 文件重命名为 `DATA.dat`

3. **修改代码中的密码**：
   - 在 `run.py` 文件中找到 `ResourceManager` 类
   - 将 `self.zip_password` 的值修改为您设置的 ZIP 密码
   - 例如：`self.zip_password = "YourZipPassword"`

### loading.dat 制作方法

loading.dat 是软件启动时显示的加载图片。制作步骤如下：

1. **准备图片**：
   - 准备一张尺寸为 700x500 像素的图片
   - 建议使用简洁、美观的图片，符合软件主题

2. **重命名图片**：
   - 将图片直接重命名为 `loading.dat`（无需压缩）
   - 支持常见的图片格式，如 PNG、JPG 等

### 注意事项

- 确保资源文件与 `runpyportscan.py` 位于同一目录
- 密码设置应确保安全性，避免使用过于简单的密码
- 图片尺寸建议按照推荐尺寸准备，以获得最佳显示效果
